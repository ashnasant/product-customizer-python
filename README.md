# High-Performance Product Customization System

This project places a user-uploaded logo onto different products like hoodies, t-shirts, and caps using Python.

## Features
- Accurate logo placement within print areas
- Mask-based blending for realistic look
- Supports multiple products (front/back/variants)

## Tech Used
- Python
- OpenCV (for image processing like masking & blending)
- NumPy (for array and image operations)

## Outputs
Sample outputs are included in this repository:
- Hoodie (front & back)
- T-shirt
- Cap (front & back)
